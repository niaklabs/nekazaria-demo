# Plan: Wire up Campañas Sanitarias index screen

## Context
The app has a campaign detail page (`/normativa/campanas/{id}`) but no **listing page** for all campaigns. The Pencil design (UMN9b) shows a screen that lists all campaigns with progress + a section for immobilized animals grouped by species/restriction type. This screen needs a link from the Normativa page.

## Changes

### 1. Migration: add `species` to `sanitary_campaigns` + `restriction_type` to `campaign_animals`
- **File**: new migration
- Add `string('species')->default('bovine')` to `sanitary_campaigns`
- Add `string('restriction_type')->nullable()` to `campaign_animals` — values: `blocked` (bloqueado) or `restricted` (con restricción)
- Update `SanitaryCampaign` model `$fillable` to include `species`
- Update `CampaignAnimal` model `$fillable` to include `restriction_type`
- Update `SanitaryCampaignFactory` to include `species`
- Update `CampaignAnimalFactory` to include `restriction_type` in the `immobilized()` state

### 2. Controller: add `index` method to `SanitaryCampaignController`
- **File**: `app/Http/Controllers/SanitaryCampaignController.php`
- Query all campaigns for the user's exploitation with eager-loaded `campaignAnimals.animal`

### 3. Route: add campaigns index route
- **File**: `routes/web.php`

### 4. Frontend: create campaigns index page
- **File**: `resources/js/pages/normativa/campanas/index.tsx` (new)

  - "ANIMALES INMOVILIZADOS" section with:

    - Yellow card: restricted animals (con restricción) with count, reason, "Ver restricción →" link to campaign
